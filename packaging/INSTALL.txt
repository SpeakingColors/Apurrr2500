Apurrr2500 install, remove and use (works fully offline)
========================================================

What you get: one VST3 plugin, Apurrr2500, a stereo bus compressor. It has an optional side-chain input (Ext SC).
The plugin collects nothing and never uses the network.

A note about the "unknown publisher" warnings
  The installers are not signed. Signing needs a paid certificate from Microsoft or Apple, and this is a free project.
  So your system shows a warning the first time. It is not a sign of a problem: the warning only says "we do not
  know who made this". You can check the file yourself: SHA256SUMS lists the checksums, and the full source code is
  at https://github.com/SpeakingColors/apurrr2500.

Windows
  Run windows\Apurrr2500-Setup.exe. It installs the VST3 plugin into C:\Program Files\Common Files\VST3 (the place DAWs look)
  and the manual into C:\Program Files\Studio 87\Apurrr2500. Close your DAW first. Installing a new version over an old one works.
  Windows may show a blue "Windows protected your PC" screen: click "More info", then "Run anyway".
  Remove: Settings > Apps > Apurrr2500 > Uninstall. It asks if you also want your saved presets deleted
  (default is No, so they stay).

macOS
  Open macos\Apurrr2500-macOS.pkg. It installs the VST3 plugin, the manual and "Uninstall Apurrr2500".
  The installer is not notarised: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall Apurrr2500" in the Applications folder. It asks if you also want your saved presets deleted
  (default is Keep).

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/Apurrr2500-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.Apurrr2500

Linux, DAW installed natively
  Extract linux/Apurrr2500-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the Apurrr2500.vst3 folder from ~/.vst3.

Your saved presets (kept on remove unless you choose to delete them)
  Windows : %APPDATA%\Studio 87\Apurrr2500\presets
  macOS   : ~/Library/Application Support/Studio 87/Apurrr2500/presets
  Linux   : ~/.local/share/Studio 87/Apurrr2500/presets  (a Flatpak DAW keeps its own copy under ~/.var/app/<DAW id>/data/)
  To delete them yourself, remove the Studio 87/Apurrr2500 folder at that place.

Side-chain: in your DAW, route another track (for example the kick) to the plugin's side-chain input,
then set Type to New and turn Ext SC on.

Manual: Apurrr2500-manual.pdf (every control, the interface tour and what is measured and what is not).
Checksums: SHA256SUMS.
